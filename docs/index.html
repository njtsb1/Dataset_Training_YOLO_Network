Workflow

1. Prepare dataset

Organize images and labels in YOLO format: images/train, labels/train, etc.

2. Train (transfer learning)

Use pretrained weights and update data/custom.yaml with your classes.

3. Detect & visualize

Run inference and save annotated images. This demo shows a simple preview flow.
